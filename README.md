# 🔴 Jogo de Terror 3D

Um jogo de terror 3D imersivo desenvolvido com **Three.js** e **JavaScript**.

## 🎮 Características

- ✅ Ambiente 3D assustador e imersivo
- ✅ Inimigos com IA que perseguem o jogador
- ✅ Sistema de saúde e HUD
- ✅ Lanterna dinâmica com sombras em tempo real
- ✅ Controles FPS suave e responsivo
- ✅ Menu principal interativo

## 🕹️ Controles

| Tecla | Ação |
|-------|------|
| **W/A/S/D** | Movimento |
| **Shift** | Correr |
| **Mouse** | Olhar ao redor |
| **Click** | Disparar/Atacar |
| **ESC** | Menu Pausa |

## 📋 Requisitos

- Node.js 16+
- npm ou yarn

## 🚀 Como executar

1. Clone o repositório:
```bash
git clone https://github.com/Emanuel-Neves-felipe/jogo-de-terror.git
cd jogo-de-terror
```

2. Instale as dependências:
```bash
npm install
```

3. Execute o servidor de desenvolvimento:
```bash
npm run dev
```

4. Abra `https://localhost:3000` no navegador

## 🛠️ Scripts

- `npm run dev` - Inicia o servidor de desenvolvimento
- `npm run build` - Compila para produção
- `npm run preview` - Visualiza o build de produção
